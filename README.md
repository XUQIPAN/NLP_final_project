# Copyright-Infringement VLM Benchmark

Supplementary code for a course project based on the paper:

> Qipan Xu, Zhenting Wang, Xiaoxiao He, Ligong Han, and Ruixiang Tang.  
> *Can Large Vision-Language Models Detect Images Copyright Infringement from GenAI?*  
> arXiv:2502.16618, 2025.

This package reproduces the public evaluation workflow for the paper's dataset statistics and vision-language-model classification metrics. It deliberately excludes the 1,000 benchmark images so that the supplementary archive remains small.

## Requirements

- Python 3.10 or newer
- No third-party Python packages
- An OpenAI-compatible multimodal Chat Completions endpoint only if model inference is required

## Dataset Images

The images are intentionally not included. Download the public dataset separately from:

```text
https://github.com/XUQIPAN/Benchmark-Dataset
```

After downloading it, either copy the images into `test/img/` or pass their location explicitly with `--images`.

## Reproduce Table 1

From the package root:

```powershell
python benchmark_eval.py summary `
  --labels data/updated_list_identity.txt `
  --output-dir results
```

Or run:

```powershell
./scripts/reproduce_table1.ps1
```

The positive ratio for each character is:

```text
positive ratio = number of positive samples / total samples for the character
```

The current public labels produce:

| Character | Positive | Negative | Ratio |
| --- | ---: | ---: | ---: |
| SpiderMan | 82 | 118 | 0.410 |
| BatMan | 103 | 97 | 0.515 |
| IronMan | 86 | 114 | 0.430 |
| SuperMan | 106 | 94 | 0.530 |
| SuperMario | 128 | 72 | 0.640 |

The paper reports 0.44 for IronMan, whereas the current public label file gives 86/200 = 0.430. This appears to be a dataset-version difference.

## Generate Predictions

### Zero-shot

```powershell
$env:OPENAI_API_KEY = "your API key"

python benchmark_eval.py run `
  --labels data/updated_list_identity.txt `
  --images D:/path/to/Benchmark-Dataset/test/img `
  --model gpt-4o-mini `
  --setting 0-shot `
  --output predictions/gpt-4o-mini_0-shot.jsonl `
  --resume
```

### In-context learning

```powershell
python benchmark_eval.py run `
  --labels data/updated_list_identity.txt `
  --images D:/path/to/Benchmark-Dataset/test/img `
  --model gpt-4o-mini `
  --setting ICL `
  --shots-per-group 3 `
  --output predictions/gpt-4o-mini_ICL.jsonl `
  --resume
```

The ICL prompt follows the structure shown in Figure 6 of the paper: positive examples, negative examples, and a query image. Because the paper does not publish the exact example indices, this implementation uses deterministic sampling with a fixed seed.

For a local OpenAI-compatible endpoint, add:

```powershell
--base-url http://127.0.0.1:8000/v1
```

Use `--limit 5` for a small smoke test or `--dry-run` to inspect the request composition without contacting an API.

## Calculate Table 2

Evaluate one or more CSV/JSONL prediction files:

```powershell
python benchmark_eval.py evaluate `
  --labels data/updated_list_identity.txt `
  --predictions `
    predictions/gpt-4o-mini_ICL.jsonl `
    predictions/gpt-4o-mini_0-shot.jsonl `
  --output-dir results
```

Or run:

```powershell
./scripts/evaluate_predictions.ps1 predictions/gpt-4o-mini_0-shot.jsonl
```

For each character:

```text
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
```

The evaluator produces:

- `metrics_long.csv`: confusion-matrix counts, precision, recall, F1, accuracy, and coverage.
- `table2_precision_recall.csv`: paper-style wide table.
- `table2_precision_recall.md`: Markdown version of the table.

## External Prediction Format

Predictions generated by another framework can be supplied as CSV or JSONL. The minimum CSV format is:

```csv
model,setting,image_id,response
my-vlm,0-shot,0.png,"Yes, Iron Man."
my-vlm,0-shot,1.png,"No."
```

The evaluator accepts `Yes`/`No` responses or an explicit binary column named `prediction`, `predicted_positive`, `is_infringing`, or `predicted_label`.

Create a full 1,000-row template with:

```powershell
python benchmark_eval.py template `
  --labels data/updated_list_identity.txt `
  --model my-vlm `
  --setting 0-shot `
  --output predictions/my-vlm.csv
```

## Reproducibility Notes

Table 1 is directly reproducible from the included labels. The exact Table 2 numbers cannot be reconstructed from the public repository alone because it does not include the original per-image model responses, exact proprietary model versions, exact ICL example indices, or every inference parameter.

The code therefore reproduces the disclosed task definition, prompt structure, and metric calculations. Exact Table 2 reproduction still requires access to the corresponding models and original experimental configuration.
